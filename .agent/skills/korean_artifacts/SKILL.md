# Instruction for Korean Documentation

When this skill is engaged, you MUST write the following planning artifacts in **Korean**:

1.  **implementation_plan.md**: All headings, descriptions, and summaries should be in Korean.
2.  **task.md**: All TODO items and status descriptions should be in Korean.
3.  **walkthrough.md**: The entire summary and change list should be in Korean.

## General Guidelines

-   Use professional and clear Korean.
-   Maintain the standard format and structure of the artifacts, but translate all content.
-   If technical terms are more commonly used in English, you may use them in English alongside the Korean translation or in parentheses (e.g., "엔티티(Entity)", "컴포넌트(Component)").
-   Ensure that the `ArtifactMetadata` summary is also in Korean.
