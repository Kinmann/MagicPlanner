# Reference Designs

This directory contains UI designs and references for the Magic Planner project.

- [API Authentication Page (Stitch)](./auth_stitch_design.html): A premium authentication page design with glassmorphism and Tailwind CSS.
- [Project Dashboard Page (Stitch)](./dashboard_stitch_design.html): A modern project dashboard design with project cards and system status bars.
- [Create New Project Modal (Stitch)](./create_project_modal_stitch_design.html): A glassmorphism modal design for creating new projects with execution mode options.
- [Project Input Phase (Stitch)](./project_input_phase_stitch_design.html): An editorial-style input page with a glass-panel textarea and guidance cards.
- [HITL Warning Modal (Stitch)](./hitl_warning_modal_stitch_design.html): A warning modal design for manual intervention (Human-in-the-Loop) with error logs and retry options.
- [Critical API Error Modal (Stitch)](./critical_api_error_modal_stitch_design.html): A critical error modal design for API issues (e.g., quota exceeded) with an "Update API Key" action.
- [Pipeline Monitoring (Stitch)](./pipeline_monitoring_stitch_design.html): A sophisticated DAG (Directed Acyclic Graph) canvas for monitoring AI orchestration pipelines with live activity logs and node status.
- [User Flow Specification - Document Detail (Stitch)](./document_detail_stitch_design.html): A premium document detail view with revision history, pass score gauge, and code editor components.
