# PRD 평가 지표 (Domain Metrics: 70점 만점)

본 지표는 Phase 3: Module PRD 검증을 위해 주입되는 배타적 평가 지표(70점 만점)입니다. 당신은 감정을 배제한 '결정론적 룰 엔진(Deterministic Rule Engine)'으로 작동해야 합니다. 자연어의 의미적 관대함을 허용하지 마십시오. 식별자 매칭, 도메인 경계, 상속 제약 위반 여부를 기계적으로 스캔하여 감점 트리거(Trigger) 조건 충족 시 즉각 감점 연산을 수행하십시오.

### Metric D: 모듈 바운더리 및 책임 캡슐화 (Module Boundary Encapsulation)
- **기본 점수: 20점**
- **[Deduction Triggers]**
    - **[-20점] [Code D-1] 타 모듈 도메인 침범:** 산출된 기능 로직이 선행 `$SOURCE_DOCUMENTS`(SAD)에 명시된 타겟 모듈의 책임을 벗어나거나 타 모듈(`MOD-XXX`)의 명시적 책임에 해당하는 경우. (즉시 삭감)
    - **[-10점] [Code D-2] 할당 외 에픽 포함:** 산출물 내에 참조된 `EPIC-XXX` 식별자가 타겟 모듈에 할당된 에픽 리스트에 존재하지 않음 (`Unmapped ID`).
    - **[-10점] [Code D-3] 마이크로 설계 개입:** 산출물 데이터에 물리적 DB 컬럼명, HTTP API 엔드포인트(URL), JSON 파라미터 타입 등 구현 레벨(FSD/ERD)의 데이터 규격이 포함됨.

### Metric E: 기능 분해의 해상도 (Feature Decomposition Specificity)
- **기본 점수: 20점**
- **[Deduction Triggers]**
    - **[-10점] [Code E-1] 동어반복 분해:** 도출된 Feature의 제목/설명이 상위 Epic의 텍스트와 의미적으로 90% 이상 동일함 (기능적 분해 없이 1:1 매핑만 수행됨).
    - **[-5점] [Code E-2] 엣지 케이스 누락:** 핵심 기능 명세에 정상 흐름(Happy Path)만 존재하고, 필수 예외 상황(데이터 부재, 권한 실패, 한도 초과 등 Unhappy Path)에 대한 분기 처리가 누락됨.
    - **[-5점] [Code E-3] 에픽 추적성 단절:** 도출된 세부 기능에 부모 에픽의 식별자(`EPIC-XXX`)가 역방향 매핑(Traceability)되지 않음.

### Metric F: 글로벌 컨텍스트 상속 정합성 (Global Context Inheritance)
- **기본 점수: 15점**
- **[Deduction Triggers]**
    - **[-5점] [Code F-1] 고스트 권한 사용:** 세부 기능에 할당된 접근 권한이 `$SOURCE_DOCUMENTS`의 RBAC 리스트에 정의된 `ROLE-XXX` 식별자와 일치하지 않음.
    - **[-5점] [Code F-2] 인가 로직 누락:** 해당 기능이 상태를 변경하는 작업(Create, Update, Delete)임에도 실행자의 최소 권한 레벨이나 데이터 소유권(Ownership) 검증 명세가 누락됨.

### Metric G: 인터페이스 대응 준비도 (Dependency & Interface Readiness)
- **기본 점수: 15점**
- **[Deduction Triggers]**
    - **[-5점] [Code G-1] I/O 맥락 누락:** SAD 기준 해당 모듈에 타 모듈과의 의존성(Inbound/Outbound)이 존재함에도 산출된 세부 기능 명세에 해당 데이터 교환을 트리거/수신하는 로직이 부재함.
    - **[-5점] [Code G-2] 통신 정책 충돌:** SAD에 정의된 통신 규격(예: Async Message Queue)과 기능 명세의 기대 동작(예: Sync Blocking 형태의 즉각적 사용자 응답 대기)이 아키텍처적으로 모순됨.
