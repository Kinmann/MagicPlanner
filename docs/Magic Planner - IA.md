## 2. 화면별 세부 명세 (Page Details)

### 2.1 [PAGE-001] 환경 설정 (Settings)

- **논리적 위치:** 애플리케이션 최초 실행 시 진입하거나, 런타임 오류 발생 시 라우팅되는 최상위 전역 환경 구성 화면.
- **매핑된 기능:** 전역 인증용 API Key 입력, 유효성 검증 및 갱신 (`FUNC-INP-01`).

### 2.2 [PAGE-002] 글로벌 대시보드 (Dashboard)

- **논리적 위치:** 인증이 완료된 사용자가 진입하는 홈 화면.
- **주요 역할:** 생성된 프로젝트 목록을 조회하고 개별 워크스페이스로 라우팅하는 진입점.

### 2.3 [PAGE-002-M01] 신규 프로젝트 생성 모달

- **논리적 위치:** 글로벌 대시보드 화면 위에 오버레이(Overlay)되는 팝업 계층.
- **매핑된 기능:** 프로젝트 명칭 및 실행 모드(AUTO/MANUAL) 입력, SQLite DB 레코드 생성 (`FUNC-PRJ-01`).

### 2.4 [PAGE-003] 프로젝트 워크스페이스

- **논리적 위치:** 특정 프로젝트가 선택되었을 때 진입하는 독립된 기획 영역.
- **매핑된 기능:** 파이프라인 구동을 위한 초기 아이디어 및 타겟 고객 텍스트 입력 수집 (`FUNC-INP-02`).

### 2.5 [PAGE-003-V01] 파이프라인 모니터링 보드

- **논리적 위치:** 프로젝트 워크스페이스 하위의 진행 상태 시각화 영역(뷰).
- **매핑된 기능:** 단방향 비순환 그래프(DAG) 노드 상태 전이 및 진행률(Progress) 표시 (`FUNC-ORC-01`), 최종 확정 산출물에 대한 마크다운 다운로드 트리거 (`FUNC-EXP-01`).

### 2.6 [PAGE-003-M01] 수동 개입(HITL) 경고 모달

- **논리적 위치:** 파이프라인 모니터링 보드 진행 중 품질 미달 시 호출되는 강제 인터럽트(Interrupt) 계층.
- **매핑된 기능:** 평가 피드백 노출 및 추가 N회 재실행/강제 승인 트리거 (`FUNC-ORC-02`).

### 2.7 [PAGE-003-M02] API 장애 경고 모달

- **논리적 위치:** 파이프라인 진행 중 외부 API 통신 장애(할당량 초과, 토큰 만료 등) 발생 시 렌더링되는 최상단 오류 계층.
- **매핑된 기능:** 에러 사유(API Error Code/Message) 노출 및 사용자 행동 유도(환경 설정 페이지로 라우팅) (`FUNC-ORC-03`).
