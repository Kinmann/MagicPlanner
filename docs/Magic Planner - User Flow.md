## 1. [FLOW-001] 초기 설정 및 다중 프로젝트 생성

- **연관 기능 명세 (Linked Func IDs):** `FUNC-INP-01`, `FUNC-PRJ-01`, `FUNC-INP-02`

| 단계 (Step) | 사용자 액션 (Action) | 시스템 응답 (System Response) |
| --- | --- | --- |
| 1 | 앱 최초 실행 시 환경 설정 화면에 진입한다. | API Key 입력 폼을 렌더링한다. |
| 2 | API Key를 입력하고 '저장' 버튼을 클릭한다. | 경량 API를 호출하여 키의 유효성을 검증하고, 성공 시 로컬에 암호화 저장 후 대시보드로 이동시킨다. |
| 3 | [예외] 유효하지 않은 API Key가 입력된 경우 | 에러 메시지를 UI에 반환하고 재입력을 요구한다. |
| 4 | 대시보드 화면에서 '새 프로젝트 생성' 버튼을 클릭한다. | 프로젝트 명칭 및 파이프라인 실행 모드(AUTO/MANUAL) 입력 모달을 렌더링한다. |
| 5 | 프로젝트 명칭(예: "AI 헬스케어 앱")과 실행 모드를 선택 후 '생성'을 누른다. | SQLite DB에 신규 `project_id` 레코드를 생성하고, 해당 프로젝트 워크스페이스로 진입한다. |
| 6 | 프로젝트 워크스페이스 내에서 초기 아이디어 텍스트를 입력하고 '가동'을 클릭한다. | 텍스트 길이 유효성(최소 50자)을 검사한다. |
| 7 | [예외] 텍스트 길이가 50자 미만일 경우 | 길이 부족 에러 메시지를 반환한다. |
| 8 | 유효한 텍스트가 입력된 경우 | 데이터를 해당 프로젝트 메모리에 적재하고, 1차 노드(PRD)의 상태를 `PENDING`에서 `READY`로 전이시킨다. |

## 2. [FLOW-002] 자동 파이프라인 모니터링 (AUTO 모드)

- **연관 기능 명세 (Linked Func IDs):** `FUNC-GEN-01`, `FUNC-EVAL-01`, `FUNC-ORC-01`

| 단계 (Step) | 사용자 액션 (Action) | 시스템 응답 (System Response) |
| --- | --- | --- |
| 1 | 프로젝트 워크스페이스 내에서 파이프라인 진행 상황을 관찰한다. | 오케스트레이터가 프로젝트의 AUTO 모드를 확인하고, `READY` 상태의 노드를 즉시 `IN_PROGRESS`로 전이시켜 루프를 가동한다. |
| 2 | 루프 진행 중 실시간 상태를 확인한다. | 생성 및 검증 엔진의 호출 상태, 현재 루프 횟수, 최고 갱신 점수를 브로드캐스트하여 UI 프로그레스 바를 갱신한다. |
| 3 | N회 루프 종료 후 평가 임계치를 통과한 노드를 확인한다. | 노드 상태를 `COMPLETED`로 DB에 커밋하고, 의존성이 해결된 후행 노드를 `READY`로 전이시킨 후 UI를 업데이트한다. |

## 3. [FLOW-003] 수동 승인 및 에러 복구 제어 (MANUAL 모드 및 HITL)

- **연관 기능 명세 (Linked Func IDs):** `FUNC-ORC-01`, `FUNC-ORC-02`

| 단계 (Step) | 사용자 액션 (Action) | 시스템 응답 (System Response) |
| --- | --- | --- |
| 1 | 프로젝트가 수동(MANUAL) 모드일 때, `READY` 상태에 도달한 특정 노드를 확인한다. | 해당 노드의 파이프라인 진행을 대기 상태로 유지하고, UI에 '실행 승인(Approval)' 버튼을 활성화한다. |
| 2 | '실행 승인' 버튼을 클릭한다. | 해당 노드를 `IN_PROGRESS`로 전이시키고 Best-of-N 루프를 시작한다. |
| 3 | [예외/에러 복구] 루프 종료 후에도 최고 점수가 임계치에 미달한 노드를 발견한다. | 시스템이 노드를 `PAUSED_HITL` 상태로 DB에 기록하고, UI에 경고 모달(미달 사유 포함)을 노출하며 파이프라인을 일시 중단한다. |
| 4 | 피드백을 확인한 후 'N회 추가 재실행' 버튼을 클릭한다. | 수동 개입 신호를 수신하여 노드 상태를 `READY`를 경유해 `IN_PROGRESS`로 복구하고 루프를 재개한다. |

## 4. [FLOW-004] 최종 산출물 다운로드

- **연관 기능 명세 (Linked Func IDs):** `FUNC-EXP-01`

| 단계 (Step) | 사용자 액션 (Action) | 시스템 응답 (System Response) |
| --- | --- | --- |
| 1 | 프로젝트 워크스페이스에서 `COMPLETED` 상태로 표시된 개별 기획 문서를 선택한다. | 해당 문서 블록 영역에 '마크다운 다운로드' 액션 버튼을 활성화한다. |
| 2 | '마크다운 다운로드' 버튼을 클릭한다. | 확정된 JSON 데이터를 마크다운 템플릿 로직에 매핑하여 변환하고, OS 네이티브 Save Dialog를 호출한다. |
| 3 | 로컬 저장 경로를 지정하고 '저장'을 누른다. | 로컬 디스크에 `.md` 파일을 영구 기록하고, 성공 여부 토스트 메시지를 UI에 브로드캐스트한다. |
