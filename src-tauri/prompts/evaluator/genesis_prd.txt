## [평가 데이터 기준]
- $SOURCE_DOCUMENTS: 사용자의 초기 요구사항 원문
- $TARGET_SCHEMA: Genesis PRD JSON 스키마 규격
- $GENERATED_DOCUMENT: 현재 평가 대상인 Genesis PRD 결과물
- $ITERATION_COUNT: 현재 생성 회차

## 1. 도메인 특화 지표 (Domain Metrics) : 70점

### Metric D: 요구사항 추출 및 메타데이터 통제 (15점)
- **감점**: 핵심 컨텍스트 누락(-10점), 메타데이터(version 1.0.0, status DRAFT) 초기화 위반(-5점), 성공 지표 비정량화(-5점).

### Metric E: 추상화 계층 통제 (15점)
- **감점**: 마이크로 설계(UI 버튼, 세부 데이터 타입, API 파라미터 등) 개입 발견 시 **즉시 0점 처리**.

### Metric F: 내부 참조 무결성 및 명제 객관화 (15점)
- **감점**: 고스트 역할 참조(user_roles에 없는 ROLE-XXX 참조) 건당 -5점, 인수 조건 모호성(True/False 판별 불가) 건당 -5점.

### Metric G: 결정론적 기술 스택 추론 (15점)
- **감점**: TBD/미정 등의 모호성 방치(-15점), 글로벌 제약 조건과 기술적 충돌(-5점).

### Metric H: 잠재 요구사항 발굴 및 설계 창의성 (10점) - Phase I/II 중점
- **감점**: 1차원적이고 진부한 나열(-10점), 도메인 특화 엣지 케이스(예: 결제/환불 로직 등) 제안 실패(-5점).

## [출력 규격]
반드시 다음 JSON 구조만을 출력하십시오. 인사말이나 설명을 붙이지 마십시오.

{
  "score": 0, // Metric A~H 합산값 (0-100)
  "is_pass": false, // score >= 85 인 경우에만 true
  "critical_errors": [], // 감점 사유 및 위반된 식별자/블록 명시
  "feedback": [] // 다음 Iteration에서 수정해야 할 Action Item 목록
}
