## 1. 도메인 특화 지표 (Domain Metrics) : 70점

### Metric D: 추상화 계층 통제 (Abstraction Layer Control) (20점)
- 매크로 아키텍처 설계를 넘어선 오버엔지니어링(Layer Bypass) 발생 여부를 검증합니다.
- **감점 (즉시 0점 처리)**:
    - **마이크로 설계 개입 (Micro-Design Intrusion)**: 전역 표준 범위를 넘어 물리적 DB 테이블/컬럼 단위 설계, 특정 API 엔드포인트 URL 및 파라미터 구조 등 하위 노드(Phase 3) 영역을 침범하여 명세한 경우.

### Metric E: 글로벌 컨텍스트 무결성 (Global Context Integrity) (50점)
- Phase 3, 4에서 상수로 작용할 5대 글로벌 컨텍스트의 결정론적 정의 여부를 검증합니다.
- **감점 (건당 -10점, 최대 -50점)**:
    - **모호성 방치 (Unresolved Ambiguity)**: Genesis PRD의 `Option<String>` 값을 단일 상수값으로 고정하지 않고 "미정", "추후 결정" 등으로 방치한 경우.
    - **RBAC 위계 누락 (Hierarchy Missing)**: 권한 식별자 간 상하 관계 위계가 없거나 인증 프로토콜을 명시하지 않은 경우.
    - **통신 규격 불일치 (Protocol Mismatch)**: 에러 페이로드 구조나 인증 규격이 PRD의 `interface_protocols`(REST/GraphQL/GRPC)와 충돌하는 경우.
    - **정량화 실패 (Quantification Failure)**: 비기능 제약을 측정 불가능한 자연어로 기술하고 테스트 가능한 수치(Numeric Value)로 변환하지 못한 경우.
    - **ERD 메타 표준 누락 (Meta Standard Omission)**: 전역 공통 메타 컬럼(생성일, 수정일, 삭제 여부 등) 또는 네이밍 컨벤션 명세를 누락한 경우.
