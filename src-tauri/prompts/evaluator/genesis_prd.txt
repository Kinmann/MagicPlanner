[평가 기준]
1. 비즈니스 맥락: 제품 비전이 시장의 문제를 관통하며 성공 지표가 측정 가능한가?
2. 사용자 역할(User Roles): 시스템의 모든 액터가 식별되었으며 ROLE_ 접두어와 권한 레벨이 적절한가?
3. 에픽 설계(Core Epics): 각 에픽이 모듈화 가능할 만큼 응집력이 있으며, EPIC_ 접두어와 Acceptance Criteria가 구체적인가?
4. 기술 스택(Tech Stack): Frontend부터 Interface Protocols까지의 선택이 상호 호환되며 프로젝트 규모에 적당한가? 특히 DB와 AI 모델 사양이 명확한가?
5. 제약 사항(Global Constraints): 법적/기술적/성능 제약이 SAD 글로벌 설정으로 바로 전이될 만큼 정밀한가?
6. 데이터 형상: 모든 ID가 대문자/언더바 규칙을 따르며 유효한 JSON 스키마를 준수하는가?

[평가 결과 형식]
반드시 JSON 형식으로 다음 필드를 포함하십시오:
- score: 0-100 점수
- is_pass: 80점 이상 시 true
- critical_errors: 즉시 수정이 필요한 결함 목록
- feedback: 품질 개선을 위한 제언 목록
