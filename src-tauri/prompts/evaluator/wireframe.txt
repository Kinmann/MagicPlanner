# Wireframe 평가 지표 (Domain Metrics: 70점 만점)

본 지표는 파이프라인의 Phase 3 병합 노드인 Wireframe 산출물에 배타적으로 적용되는 70점 만점의 특화 검증 기준입니다. FSD, User Flow, IA가 하나의 시각적 UI 명세로 결합되었는지 검증합니다.

### Metric D: 데이터 바인딩 및 가시성 (Data Binding & Visibility)
- **기본 점수: 15점**
- **[감점 트리거]**
    - **[-10점] 출력 데이터 매핑 누락:** FSD 조회/출력 데이터가 화면의 어느 텍스트/표에도 배치되지 않음.
    - **[-10점] 입력 폼 컴포넌트 결함:** FSD 필수 입력 데이터를 수집하기 위한 UI 컴포넌트 누락.
    - **[-5점/건] 환각 UI 요소:** 선행 문서에 없는 임의 데이터 지표(허위 통계 등)를 시각적으로 추가.

### Metric E: 엣지 케이스 상태 제어 (Edge Case State Control)
- **기본 점수: 10점**
- **[감점 트리거]**
    - **[-10점] 빈 상태(Empty State) 설계 누락:** 데이터 0건 시 사용자 피드백 및 유도 동선(CTA) 영역 누락.
    - **[-10점] 피드백 컴포넌트 부재:** 로딩 인디케이터(Skeleton UI 등) 또는 에러 메시지(Toast, Alert 등) 배치/조건 미명시.

### Metric F: 상호작용 및 액션 트리거 정합성 (Interaction & Action Trigger Consistency)
- **기본 점수: 10점**
- **[감점 트리거]**
    - **[-10점] 실행 트리거 누락:** FSD의 상태 변경 기능(삭제, 저장 등)을 명령할 버튼/영역 부재.
    - **[-5점/건] 액션 피드백 부재:** 버튼 클릭 직후의 상태 변화(Disabled 등) 마이크로 인터랙션 명세 누락.

### Metric G: 추적성 및 FSD 기능 매핑 (Traceability & FSD Mapping)
- **기본 점수: 10점**
- **[Critical Error 할당 조건]**
    - **No Orphan ID 위반**: 선행 IA 또는 FSD에 존재하지 않는 컴포넌트를 생성하거나, `mapped_element_id` 또는 `mapped_func_id` 매핑이 누락된 경우.
    - **ID 패턴 불일치**: 모든 컴포넌트의 `component_id`가 `CMP-001` 형식의 정규식(`^CMP-[0-9]{3}$`)을 준수하지 않음.
    - **매핑 실재성 결여**: `mapped_element_id`(`^ELM-[0-9]{3}$`) 또는 `mapped_func_id`(`^FUNC-[0-9]{3}$`)가 선행 문서에 존재하지 않음.
- **[감점 트리거]**
    - **[-10점] 근거 없는 UI**: 매핑 ID가 모두 누락되어 IA나 FSD와의 연결 고리가 없음.
    - **[-5점/건] 기능 오매핑**: FSD 기능과 무관한 UI 요소에 `mapped_func_id`가 할당됨.

### Metric H: 공간적 IA 및 네비게이션 준수 (Spatial IA & Navigation Compliance)
- **기본 점수: 10점**
- **[감점 트리거]**
    - **[-10점] 계층 탐색 구조 누락:** IA의 상/하위 메뉴 이동용 UI(탭, 사이드바, 뒤로가기 등) 미배치로 인한 경로 고립.
    - **[-5점/건] 레이아웃 모순:** IA의 모달을 풀 페이지로 설계하는 등 시각적 계층과 논리적 계층의 충돌.

### Metric I: 모듈 책임 경계 정합성 (Module Boundary Consistency)
- **기본 점수: 15점**
- **[감점 트리거]**
    - **[-15점] 타 모듈 UI 직접 설계**: `[Core Responsibility]`에 정의되지 않은 타 모듈 소유의 데이터나 비즈니스 로직을 상세 UI 컴포넌트로 구현함. (환각 발생)
    - **[-10점] 책임 범위 외 데이터 노출**: FSD 및 모듈 책임 범위를 벗어나는 외부 데이터를 임의로 시각화함.
    - **[-5점/건] 연동 설계 위반**: 타 모듈과의 데이터 연동 시 `[Dependencies]`를 무시하고 독자적인 비즈니스 로직을 UI에 삽입함.
