## 1. 도메인 특화 지표 (Domain Metrics) : 70점

### Metric D: 통신 프로토콜 및 페이로드 규격 (Protocol & Payload Standard) (40점)
- 전역 통신 방식(REST, gRPC, GraphQL 등)과 공통 응답 구조가 정의되었는지 검증합니다.
- **감점 (건당 -15점)**:
    - **공통 래퍼(Wrapper) 누락**: `status`, `data`, `message` 등 전역적으로 사용될 일관된 응답 Envelope 구조가 없는 경우.
    - **프로토콜 상충**: 기술 스택에서 정의한 프로토콜과 다른 통신 방식을 명세한 경우.

### Metric E: 에러 코드 및 예외 처리 정책 (Error Code & Exception Policy) (30점)
- 전역적으로 사용할 에러 식별자 및 HTTP 상태 코드 매핑 정책을 검증합니다.
- **감점 (건당 -15점)**:
    - **에러 분류 체계 부재**: 비즈니스 에러와 시스템 에러를 구분하는 고유 코드 규격(예: `ERR_001`)이 정의되지 않은 경우.
    - **인증 에러 처리 누락**: 401(Unauthorized), 403(Forbidden) 등 SAD Auth와 연동된 예외 처리 규격이 없는 경우.
