# ERD 평가 지표

생성일: 2026년 3월 29일 오후 1:52

**[Objective]**
본 지표는 파이프라인의 Phase 2 (Track B) 노드인 ERD 산출물에 배타적으로 적용되는 70점 만점의 특화 검증 기준입니다. 당신은 선행 문서인 FSD(기능 명세서)의 `data_requirements`가 로컬 단일 파일 데이터베이스(SQLite) 환경에 맞추어 무결성을 갖춘 테이블 구조로 치환되었는지 검증하는 데이터베이스 관리자(DBA)처럼 행동해야 합니다. 정규화 위반, 참조 무결성 훼손, 제약 조건 누락을 엄격하게 적발하여 감점 연산을 수행하십시오.

## 특화 평가 지표 (Domain Metrics) : 총점 70점

**[점수 연산 원칙]**

- 각 Metric의 최종 점수 산출 공식: `MAX(0, 기본 점수 - 누적 감점)`
- 감점 발생 시 해당 사유를 반드시 최종 출력의 `critical_errors` 배열에 기록하십시오.

### Metric D: 정규화 및 엔티티 설계 무결성 (Normalization & Entity Integrity)

데이터의 중복을 최소화하고 갱신 이상(Update Anomaly)을 방지하기 위해 최소 3정규형(3NF) 수준의 엔티티 분리가 이루어졌는지 검증합니다.

- **기본 점수:** 20점
- **[감점 트리거]**
    - **[-10점] 제1정규형(1NF) 위반:** 다중 값(Multi-valued)을 가지는 배열이나 복잡한 JSON 구조를 단일 컬럼에 통째로 저장하도록 설계하여 관계형 DB의 이점을 훼손한 경우. (단, 스키마리스 저장이 불가피한 특수 메타데이터 제외)
    - **[-10점] 데이터 중복 및 역정규화 남용:** 조인(Join) 연산을 회피할 목적으로 여러 테이블에 동일한 원본 데이터를 중복 적재하여 단일 진실 공급원(SSOT) 원칙을 위배한 경우.
    - **[-5점/건] 식별자(PK) 결함:** 엔티티에 유일성을 보장하는 기본키(Primary Key)가 누락되었거나, 복합키 사용 시 식별자로서의 적합성이 떨어지는 경우.

### Metric E: 관계 및 참조 무결성 (Relationship & Referential Integrity)

엔티티 간의 논리적 연결(1:1, 1:N, N:M)이 명확하며, 데이터 삭제/수정 시 고아 데이터(Orphan Data)를 방지할 물리적 제약이 명세되었는지 평가합니다.

- **기본 점수:** 20점
- **[감점 트리거]**
    - **[-10점] N:M (다대다) 관계의 논리적 방치:** 다대다 관계가 발생하는 엔티티 쌍 사이에 이를 해소할 교차 테이블(Mapping/Junction Table)이 물리적으로 설계되지 않은 경우.
    - **[-10점] 연쇄 참조 제약(Cascade) 누락:** 부모 레코드 삭제 또는 수정 시 자식 레코드의 처리 정책(`ON DELETE CASCADE`, `SET NULL`, `RESTRICT` 등)이 명시되지 않아 참조 무결성이 보장되지 않는 경우.
    - **[-5점/건] 카디널리티(Cardinality) 오류:** FSD의 비즈니스 로직 상 1:N이어야 할 관계가 1:1로 잘못 매핑되는 등 방향성과 다중성이 비즈니스 규칙과 모순된 경우.

### Metric F: 물리적 데이터 타입 및 제약 조건의 엄밀성 (Strictness of Data Types & Constraints)

PRD에서 정의된 아키텍처 제약(SQLite)에 부합하는 데이터 타입이 적용되었으며, 컬럼 단위의 방어적 제약이 설정되었는지 검증합니다.

- **기본 점수:** 15점
- **[감점 트리거]**
    - **[-10점] 아키텍처 제약 위반 (SQLite 불일치):** SQLite에서 공식 지원하지 않는 데이터 타입(예: `ENUM`, `VARCHAR(255)`의 엄격한 길이 제한 등)에 의존하는 설계를 하여 로컬 구동 시 예외를 유발하는 경우. (SQLite의 동적 타이핑 및 5가지 기본 스토리지 클래스 고려 요망)
    - **[-5점/건] 필수 제약 조건 누락:** 비즈니스 로직상 반드시 값이 존재해야 하거나 고유해야 하는 컬럼에 `NOT NULL`, `UNIQUE`, `DEFAULT` 제약 조건이 명세되지 않은 경우.

### Metric G: FSD 데이터 요구사항 정합성 (Consistency with FSD Data Requirements)

선행 산출물인 FSD에 명시된 모든 `data_requirements` 속성들이 누락 없이 ERD 테이블 및 컬럼으로 매핑되었는지 교차 검증합니다.

- **기본 점수:** 15점
- **[감점 트리거]**
    - **[-10점] 데이터 유실 (Missing Data Attribute):** FSD 특정 기능 수행을 위해 명시적으로 요구된 데이터 필드가 ERD의 어떤 테이블에도 컬럼으로 존재하지 않는 경우.
    - **[-5점/건] 환각 컬럼 (Hallucinated Column):** FSD에서 전혀 언급된 바 없으며 시스템 동작에도 불필요한 컬럼이나 테이블을 임의로 창작하여 추가한 경우. (단, `created_at`, `updated_at` 등 시스템 기본 감사(Audit) 컬럼은 환각으로 간주하지 않음)
