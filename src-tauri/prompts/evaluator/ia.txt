# IA 평가 지표 (Domain Metrics: 70점 만점)

본 지표는 파이프라인의 Phase 2 (Track A) 노드인 IA 산출물에 배타적으로 적용되는 70점 만점의 특화 검증 기준입니다. FSD와 User Flow가 모순 없이 계층적 화면 구조로 매핑되었는지 검증합니다.

### Metric D: 구조적 MECE 및 분류 체계 (Structural MECE & Taxonomy)
- **기본 점수: 15점**
- **[감점 트리거]**
    - **[-10점] 계층 모순 및 중복:** 동일 목적의 화면이 여러 경로에 중복 배치되어 SSOT 원칙 훼손.
    - **[-10점] 고아 화면:** User Flow의 특정 화면/모달이 IA 카테고리에서 누락.
    - **[-5점/건] 모호한 레이블링:** "기타" 등 추상적 메뉴명 사용으로 인지적 혼란 유발.

### Metric E: 탐색 뎁스(Depth) 및 인지 효율성 (Navigation Depth & Cognitive Efficiency)
- **기본 점수: 10점**
- **[감점 트리거]**
    - **[-10점] 과도한 뎁스:** 정당성 없이 4단계 이상 깊어져 컨텍스트 유실 위험 발생.
    - **[-5점/건] 상향 탐색 경로 부재:** Breadcrumb, GNB 등 상위/메인 복귀 장치 누락.

### Metric F: 상태 기반 가시성 제어 (State-based Visibility Control)
- **기본 점수: 15점**
- **[감점 트리거]**
    - **[-10점] 권한/상태 분리 누락:** 초기화 전(PENDING)과 정상 운영(READY) 상태의 메뉴 구조가 동일하게 설계됨.
    - **[-10점] 전역 인터럽트 계층 부재:** 장애나 수동 개입 발생 시 화면을 덮는 전역 모달(Global Modal) 정의 누락.

### Metric G: 추적성 및 선행 산출물 매핑 (Traceability & Upstream Mapping)
- **기본 점수: 15점**
- **[Critical Error 할당 조건]**
    - **No Orphan ID 위반**: 선행 User Flow 또는 FSD에 존재하지 않는 화면/요소를 생성하거나, `mapped_user_flow_id` 또는 `mapped_func_id` 매핑이 누락된 경우.
    - **ID 패턴 불일치**: `screen_id`는 `^SCR-[0-9]{3}$`, `element_id`는 `^ELM-[0-9]{3}$` 형식을 준수해야 함.
    - **매핑 실재성 결여**: `mapped_user_flow_id`(`^FLOW-[0-9]{3}$`) 또는 `mapped_func_id`(`^FUNC-[0-9]{3}$`)가 선행 문서에 존재하지 않음.
- **[감점 트리거]**
    - [-10점] 근거 없는 화면: 매핑 ID가 모두 누락되어 선행 문서와의 연결 고리가 없음.
    - [-10점] 식별자 추적성 훼손: 매핑 ID가 선행 문서의 실제 식별자와 일치하지 않아 논리적 연결이 끊어짐.
    - [-10점] 기능 오매핑: `mapped_func_id`에 연결된 FSD 기능이 해당 화면의 성격과 명백히 불일치함.
    - **[-5점/건] 명칭 파편화**: 선행 문서의 명칭을 IA에서 임의 유의어(예: 설정 -> 환경설정)로 변경하여 추적성 훼손.

### Metric H: 모듈 책임 경계 정합성 (Module Boundary Consistency)
- **기본 점수: 15점**
- **[감점 트리거]**
    - **[-15점] 타 모듈 화면 설계**: `[Core Responsibility]`에 정의되지 않은 타 모듈 소유의 화면을 IA 구조 내에 상세 설계함. (환각 발생)
    - **[-10점] 인터페이스 오설계**: 타 모듈과의 접점을 `[Dependencies]`에 정의된 방식이 아닌 직접적인 구조적 결합으로 설계함.
    - **[-5점/건] 책임 범위를 벗어난 기능 배치**: 본 모듈의 핵심 책임(`Core Responsibility`)과 무관한 기능을 특정 화면에 배치함.
