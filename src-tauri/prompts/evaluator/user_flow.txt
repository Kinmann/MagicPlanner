# User Flow 평가 지표 (Domain Metrics: 70점 만점)

본 지표는 파이프라인의 Phase 2 (Track A) 노드인 User Flow 산출물에 배타적으로 적용되는 70점 만점의 특화 검증 기준입니다. FSD의 명세가 사용자 관점의 화면 흐름으로 완벽히 치환되었는지 검증합니다.

### Metric D: 동선의 무결성 및 연속성 (Integrity & Continuity of Flow)
- **기본 점수: 15점**
- **[감점 트리거]**
    - **[-10점] 데드엔드 (Dead-end):** 특정 단계에서 다음 단계 전환 액션이 정의되지 않아 교착 상태 발생.
    - **[-10점] 도달 불가 상태:** 화면/상태가 정의되어 있으나 진입 트리거/선행 동선이 부재.
    - **[-5점/건] 강제 이탈 동선 부재:** 작업을 취소하고 안전한 상태(대시보드 등)로 복구할 수 있는 이탈 경로(Cancel/Back) 누락.

### Metric E: 예외 및 복구 동선 커버리지 (Exception & Recovery Flow Coverage)
- **기본 점수: 15점**
- **[감점 트리거]**
    - **[-10점] 오류 피드백 누락:** FSD 예외 상태 발생 시 시각적 알림(Error UI/Toast 등) 누락.
    - **[-10점] 복구 동선 부재:** 오류 인지 후 액션(재시도, 설정 변경 등)으로 연결되는 후속 동선 전무.

### Metric F: 시스템 상태의 시각적 동기화 (Visual Synchronization of System States)
- **기본 점수: 10점**
- **[감점 트리거]**
    - **[-10점] 지연 상태(Loading) 누락:** 무거운 통신 작업 시 처리 상태(Processing)를 보여주는 전이 단계 생략.
    - **[-5점/건] 인터럽트 대응 누락:** 수동 개입(HITL) 발생 시 사용자 승인/반려 요구 인터럽트 동선 누락.

### Metric G: 추적성 및 FSD 기능 매핑 (Traceability & FSD Mapping)
- **기본 점수: 15점**
- **[Critical Error 할당 조건]**
    - **No Orphan ID 위반**: 선행 FSD에 존재하지 않는 사용자 흐름(Node)을 생성하거나, `mapped_func_ids` 매핑이 누락된 경우.
    - **ID 패턴 불일치**: 모든 노드의 `id`가 `FLOW-001` 형식의 정규식(`^FLOW-[0-9]{3}$`)을 준수하지 않음.
    - **매핑 실재성 결여**: `mapped_func_ids` 배열 내의 ID가 선행 FSD에 존재하지 않거나 형식이 틀림 (`^FUNC-[0-9]{3}$`).
- **[감점 트리거]**
    - **[-10점] 미매핑 기능 존재:** FSD 기능이 어떤 시나리오에도 포함되지 않아 사용자가 트리거할 수 없음.
    - **[-5점/건] 환각 액션:** User Flow에는 정의되었으나 FSD에 해당 액션 처리 근거 로직이 전무.

### Metric H: 모듈 책임 경계 정합성 (Module Boundary Consistency)
- **기본 점수: 15점**
- **[감점 트리거]**
    - **[-15점] 타 모듈 로직 침범**: `[Core Responsibility]`에 정의되지 않은 타 모듈의 핵심 책임을 수행하는 시나리오가 포함됨. (환각 발생)
    - **[-10점] 의존성 미준수**: `[Dependencies]`에 정의되지 않은 외부 시스템/모듈과의 불필요하거나 정의되지 않은 연동 발생.
    - **[-5점/건] 책임 모호성**: 본 모듈의 역할(`Core Responsibility`)이 아닌 부가적인 기능 로직이 독자적으로 설계됨.
