# User Flow 평가 지표

생성일: 2026년 3월 29일 오후 1:52

**[Objective]**
본 지표는 파이프라인의 Phase 2 (Track A) 노드인 User Flow 산출물에 배타적으로 적용되는 70점 만점의 특화 검증 기준입니다. 당신은 선행 문서인 FSD(기능 명세서)의 모든 명세가 사용자 관점의 화면 흐름으로 완벽히 치환되었는지 검증하는 논리 분석기(Logic Analyzer)처럼 행동해야 합니다. 동선의 단절, 상태 표현의 누락, 예외 상황에서의 사용자 갇힘(Trapped) 현상을 엄격하게 적발하여 감점 연산을 수행하십시오.

## 특화 평가 지표 (Domain Metrics) : 총점 70점

**[점수 연산 원칙]**

- 각 Metric의 최종 점수 산출 공식: `MAX(0, 기본 점수 - 누적 감점)`
- 감점 발생 시 해당 사유를 반드시 최종 출력의 `critical_errors` 배열에 기록하십시오.

### Metric D: 동선의 무결성 및 연속성 (Integrity & Continuity of Flow)

모든 사용자 동선이 명확한 진입점(Entry)과 종료점(Exit)을 가지며, 논리적으로 고립된 구간이 없는지 검증합니다.

- **기본 점수:** 20점
- **[감점 트리거]**
    - **[-10점] 데드엔드 (Dead-end):** 동선의 특정 단계에서 다음 단계로의 전환(Transition) 액션이 정의되지 않아 사용자가 더 이상 진행도, 이탈도 할 수 없는 논리적 교착 상태에 빠지는 경우.
    - **[-10점] 도달 불가 상태 (Unreachable Node):** 특정 화면이나 상태가 정의되어 있으나, 해당 단계로 진입하기 위한 트리거(Trigger)나 선행 동선이 존재하지 않는 경우.
    - **[-5점/건] 강제 이탈 동선 부재:** 사용자가 프로세스 진행 중 언제든지 의도적으로 작업을 취소하고 안전한 상태(예: 대시보드 또는 메인 화면)로 복귀할 수 있는 범용적 이탈(Cancel/Back) 동선이 누락된 경우.

### Metric E: 예외 및 복구 동선 커버리지 (Exception & Recovery Flow Coverage)

FSD에 명시된 예외 케이스(Edge Cases)가 사용자 화면 상의 오류 인지 및 복구 흐름으로 정확하게 번역되었는지 평가합니다.

- **기본 점수:** 20점
- **[감점 트리거]**
    - **[-10점] 오류 피드백 누락 (Missing Error Feedback):** FSD에 정의된 예외 상태(예: API 통신 오류, 유효성 검사 실패 등) 발생 시, 이를 사용자에게 시각적으로 알리는 동선(Error UI/Toast/Modal 노출)이 누락된 경우.
    - **[-10점] 복구 동선 부재 (Missing Recovery Flow):** 오류 상태 인지 후, 사용자가 문제를 해결하기 위해 취할 수 있는 구체적인 액션(예: '재시도', '설정 변경 후 다시 진입', '무시하고 계속')으로 연결되는 후속 동선이 없는 경우.

### Metric F: 시스템 상태의 시각적 동기화 (Visual Synchronization of System States)

데이터베이스 트랜잭션이나 LLM 프롬프트 처리 등 대기 시간이 발생하는 비동기(Async) 작업이 사용자 동선에 올바르게 반영되었는지 검증합니다.

- **기본 점수:** 15점
- **[감점 트리거]**
    - **[-10점] 지연 상태(Loading/Processing) 누락:** FSD 기준 서버/DB 통신이 발생하는 무거운 기능임에도 불구하고, 액션 발생 후 결과 도출 사이에 로딩, 프로그레스 바 등 시스템 처리 상태(Processing State)를 보여주는 전이 단계가 생략된 경우.
    - **[-5점/건] 인터럽트 대응 누락:** 시스템 아키텍처 상 수동 개입(HITL)이 필요하여 파이프라인이 `PAUSED` 상태가 되었을 때, 사용자의 승인/반려를 요구하는 인터럽트(Interrupt) 동선이 명세되지 않은 경우.

### Metric G: FSD 기능 매핑의 포괄성 (Comprehensiveness of FSD Mapping)

FSD에서 정의된 모든 기능(`func_id`)이 하나 이상의 User Flow 단계와 누락 없이 연결되어 있는지 교차 검증합니다.

- **기본 점수:** 15점
- **[감점 트리거]**
    - **[-10점] 미매핑 기능 존재 (Unmapped Function):** FSD에 명시된 주요 기능이 어떤 User Flow 시나리오에도 포함되지 않아, 백엔드 로직은 존재하나 사용자가 트리거할 수 없는 상태인 경우.
    - **[-5점/건] 환각 액션 (Hallucinated Action):** User Flow에서 사용자가 특정 액션(예: '일괄 다운로드 클릭')을 수행한다고 정의했으나, 해당 액션을 처리할 근거 로직이 FSD에 전혀 정의되어 있지 않은 경우.
