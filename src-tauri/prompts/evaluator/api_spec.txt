# API 평가 지표 (Domain Metrics: 70점 만점)

본 지표는 파이프라인의 Phase 3 병합 노드인 API 명세서 산출물에 배타적으로 적용되는 70점 만점의 특화 검증 기준입니다. FSD의 비즈니스 로직과 ERD의 물리 구조가 인터페이스 규약으로 완벽히 치환되었는지 검증합니다.

### Metric D: RESTful 아키텍처 및 엔드포인트 설계 무결성 (RESTful Architecture Integrity)
- **기본 점수: 20점**
- **[감점 트리거]**
    - **[-10점] 행위 중심의 URI:** 동사(getUsers, createProject 등) 사용.
    - **[-10점] HTTP 메서드 오용:** 조회에 POST, 생성에 GET 사용 등 시맨틱 위반.
    - **[-5점/건] 계층 구조 논리 오류:** 리소스 종속 관계가 ERD 모델과 불일치하거나 경로 파편화.

### Metric E: 요청/응답 페이로드 스키마 정합성 (Payload Schema Consistency)
- **기본 점수: 20점**
- **[감점 트리거]**
    - **[-10점] 스키마 타입 불일치:** API 페이로드와 ERD 컬럼 타입 충돌.
    - **[-10점] 필수 파라미터 누락:** ERD의 `NOT NULL` 필드나 PK/FK가 명세에서 누락.
    - **[-5점/건] 블랙박스형 응답 구조:** 구체적 속성 없이 "성공 시 데이터 반환" 등 모호한 서술.

### Metric F: 상태 코드 및 예외 메타데이터 세분화 (Granularity of Status Codes & Exceptions)
- **기본 점수: 15점**
- **[감점 트리거]**
    - **[-10점] 해피 패스 편향:** 성공(200/201) 코드만 존재하고 실패 상황(4xx) 전무.
    - **[-10점] 에러 메타데이터 누락:** 오류 원인 파악을 위한 에러 메시지(또는 코드) 스키마 정의 누락.
    - **[-5점/건] 상태 코드 오용:** 권한 없음(401)에 400 반환 등 표준 의미 오용.

### Metric G: 대규모 데이터 제어 및 시스템 방어 기제 (Data Control & System Defense)
- **기본 점수: 15점**
- **[감점 트리거]**
    - **[-10점] 페이징/리미트 부재:** 다건 목록 조회(GET) 시 `page`, `limit`, `offset` 등 파라미터 누락.
    - **[-5점/건] 정렬/필터링 기준 누락:** 데이터 활용을 위한 최소한의 `sort_by`, `order` 명세 누락.
