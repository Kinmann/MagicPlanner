## 1. 도메인 특화 지표 (Domain Metrics) : 70점

### Metric D: Bounded Context 응집도 및 정의 (Cohesion & Definition) (40점)
- 각 모듈이 명확한 비즈니스 경계를 가지고 독립적으로 정의되었는지 검증합니다.
- **감점 (건당 -15점)**:
    - **모듈 과립화/파편화**: Bounded Context 단위로 묶이지 않고 단순 CRUD나 테이블 단위로 지나치게 잘게 쪼개진 경우.
    - **책임 모호성**: 각 모듈의 `core_responsibility`가 다른 모듈과 중복되거나 명확하지 않은 경우.

### Metric E: 모듈 식별자 정합성 (Module ID Integrity) (30점)
- 모듈 ID 규격과 네이밍의 적절성을 검증합니다.
- **감점 (건당 -10점)**:
    - **ID 중복 또는 누락**: 시스템 내에서 유일해야 하는 모듈 식별자가 중복되거나 형식이 일치하지 않는 경우.
    - **네이밍 컨벤션 위반**: 전역 네이밍 가이드(SAD Core ERD 등)를 따르지 않은 경우.
